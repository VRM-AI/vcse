# Branding Guide

## Canonical Hierarchy

- Category: Correctness Models (CMs)
- Engine: VCSE (Verifier-Centered Symbolic Engine)
- Brand: VelariumAI
- Hosting Organization: VRM-AI

## Canonical Definitions

Definition:
Correctness Models are systems designed to produce outputs that are verifiably correct through explicit reasoning, validation, provenance, and controlled inference rather than probabilistic generation.

Engine:
VCSE is the verification and reasoning engine for Correctness Models (CMs).

## Approved Phrases

- LLMs provide the creative spark. CMs provide the logical grounding.
- LLMs generate ideas. CMs guarantee correctness.
- LLMs guess. CMs prove.
- verification and reasoning engine
- verifiably correct
- logical grounding
- explicit reasoning

## Disallowed Phrases

- Verifier Reasoning Model (as primary category)
- Verified Reasoning Model (as primary category)
- Verifiable Model (as primary category)
- VRM (as primary category)
- Symbolic reasoning system (as primary category)

## VRM-AI Usage Rule

VRM-AI is infrastructure context only (hosting/development organization) and must not be positioned as a product, category, system type, or primary brand.
